Как добавить новую запись
Все данные хранятся прямо в этом файле (index.html), в массивах gostData / materialsData / literatureData ближе к концу файла. Чтобы добавить строку: открой файл на GitHub → нажми на карандаш (Edit) → скопируй существующую строку по образцу, поменяй значения → Commit changes. Сайт обновится сам через 1–2 минуты.
Как подключить файлы (PDF ГОСТов, Анурьев и т.д.)
В таблицах есть ссылка «Мой файл» — она ведёт на файл в папке docs/ внутри репозитория, например docs/gost-1050-2013.pdf. Пока файла там нет — ссылка не работает (404), это нормально.

1. Скачай нужный PDF легально (ГОСТ — на docs.cntd.ru, standartgost.ru, protect.gost.ru; Анурьева — если купил бумажную/электронную версию, отсканируй или используй свою легальную копию).
2. В репозитории на GitHub создай папку docs (Add file → Create new file → напиши docs/имя-файла.pdf — папка создастся сама) и загрузи туда файл с ровно таким именем, как в колонке file в данных (например gost-1050-2013.pdf).
3. Ссылка «Мой файл» в таблице заработает автоматически.

Про Анурьева отдельно: это книга под авторским правом, я не могу подобрать или прислать ссылку на её скачивание — сюда нужно класть только свою легально полученную копию.

Раздел 07 · ISO 15 / ISO 104 / ГОСТ 8338-75

Подшипники качения

Стандартные размеры ISO — по ним делают все производители, включая SKF, поэтому подшипник с этими d/D/B взаимозаменяем независимо от бренда.

Подбор по нагрузке и ресурсу

Диаметр вала, радиальная нагрузка, обороты и желаемый ресурс — калькулятор посчитает реальный ресурс L10h для каждого подшипника с этим посадочным диаметром и подсветит те, кто проходит по запасу.

Расчёт для чистой радиальной нагрузки (P = Fr). При заметной осевой нагрузке нужна эквивалентная динамическая нагрузка P = X·Fr + Y·Fa по каталогу производителя — здесь это не учтено, так что для смешанной нагрузки запас занижай вручную.

Раздел 10 · ГОСТ 2.309-73 / ISO 1302

Шероховатость поверхности

Ra — среднее арифметическое отклонение профиля, основной параметр на современных чертежах (пишется как «Ra 3.2»). Rz — высота неровностей по 10 точкам, встречается на старых чертежах.

Ra, мкмRz, мкм (ориент.)Типичная обработкаГде встречается
Ряд Ra — стандартный предпочтительный ряд (каждое значение вдвое меньше предыдущего). Столбец Rz — грубая оценка по правилу Rz ≈ 4×Ra для точения/фрезерования; для шлифования и полировки соотношение может быть другим (Rz ≈ 5–7×Ra) — если Rz задан на чертеже явно, всегда используй его, а не пересчёт.

Раздел 13 · калькулятор · линейная теория упругости

Балка на прогиб

Максимальный прогиб и изгибающий момент для простой балки на двух опорах или консоли. Момент инерции I возьми со страницы «Сечения» для своего профиля.

Формулы линейной теории упругости для малых прогибов однородного сечения по всей длине. Не учитывает концентраторы напряжений, собственный вес балки и пластические деформации — для ответственных конструкций проверяй расчётом с запасом.
